# YZ50 Foundational Models Study & Implementation Repository

Bu repo, **YZ50** bünyesinde yapay zekâ temel modelleri (*foundation models*) üzerine yürütülen haftalık çalışma, araştırma ve kodlama görevlerini içermektedir. Derin öğrenme mimarilerinin teorik altyapısı ve pratik uygulamaları haftalık modüller halinde depolanmaktadır.

---

## 🎯 Amaç ve Kapsam

* Derin öğrenme ve temel model mimarilerini (Transformers, Diffusion, Flow Matching vb.) sıfırdan veya uçtan uca uygulamalı olarak incelemek.
* Teorik matematiksel temelleri koda dönüştürmek.
* Haftalık teknik görevler üzerinden temiz, modüler ve reproduktif (yinelenebilir) bir kod külliyatı oluşturmak.
